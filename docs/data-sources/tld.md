# openprovider_tld (Data Source)

Reads which contact roles a domain of an extension takes. An extension that Openprovider does not offer is an error. The `openprovider_domain_check` data source tells whether a name is available.

## Example Usage

```terraform
data "openprovider_tld" "cfd" {
  name = "cfd"
}

output "cfd_takes_an_admin_handle" {
  value = data.openprovider_tld.cfd.admin_handle_supported
}
```

### Required

- `name` (String) The extension, without the dot (e.g., `com`).

### Read-Only

- `admin_handle_supported` (Boolean) Whether a domain of the extension takes a admin handle. Null when the API does not report it.
- `billing_handle_supported` (Boolean) Whether a domain of the extension takes a billing handle. Null when the API does not report it.
