# openprovider_customer_exists (Data Source)

Reads whether the account holds a customer handle. Unlike the `openprovider_customer` data source, this keeps the data of the customer out of the state: only the handle and the answer reach it. A deleted customer does not exist. A failed read is an error.

## Example Usage

```terraform
data "openprovider_customer_exists" "owner" {
  handle = "XX123456-XX"
}

output "owner_handle_exists" {
  value = data.openprovider_customer_exists.owner.exists
}
```
