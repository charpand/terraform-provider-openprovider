# openprovider_nsgroup (Data Source)

Retrieves information about an OpenProvider nameserver group.

## Example Usage

```terraform
data "openprovider_nsgroup" "example" {
  name = "my-ns-group"
}
```

With `allow_missing`, a group that does not exist is a result and not an error:

```terraform
# Read a group that may not exist. A missing group is a result, not an error.
data "openprovider_nsgroup" "shared" {
  name          = "my-ns-group"
  allow_missing = true
}

output "shared_group_exists" {
  value = data.openprovider_nsgroup.shared.exists
}
```
