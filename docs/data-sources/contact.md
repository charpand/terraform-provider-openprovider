# openprovider_contact (Data Source)

Retrieves a contact by its numeric id, including its control panel IP lists. Use it to read the current whitelist before managing it with `openprovider_rcp_ip_whitelist`.

## Example Usage

```terraform
data "openprovider_contact" "login" {
  id = "123456"
}

output "current_whitelist" {
  value = data.openprovider_contact.login.rcp_allow
}
```

### Required

- `id` (String) The numeric id of the contact.

### Read-Only

- `email` (String) The email address of the contact.
- `rcp_allow` (Set of String) The control panel IP whitelist. Empty when no whitelist is set.
- `rcp_deny` (Set of String) The control panel IP blacklist.
- `role` (String) The role of the contact.
- `username` (String) The login name of the contact.
